# Security Policy

LogJam has no server component and stores its journal locally. Security-sensitive reports may still concern backup validation, unintended data disclosure, or maliciously crafted import files.

Please do not publish exploit details in a public issue before maintainers have had a reasonable opportunity to investigate. Use GitHub's private vulnerability reporting feature if it is enabled for the repository. Otherwise, open a minimal issue asking the maintainer for a private contact channel.

Only the latest revision on the default branch is currently supported.

# Changelog

All notable changes to LogJam will be documented in this file.

## 1.0.0 - 2026-10-07

- Added local journals for films, books, and classical music.
- Added quick and detailed logging, repeat encounters, editing, and deletion.
- Added custom cover photos and generated category artwork.
- Added English and Simplified Chinese interfaces.
- Added local SwiftData persistence.
- Added versioned JSON backup and restore with validation.
- Added archive and restore unit tests.
- Prepared the project for its initial open-source release.
